# 📘 Digital Design Circuits using Verilog HDL

A collection of fundamental digital circuits implemented in **Verilog HDL** for learning, practice, and reference.

This repository covers essential concepts of Digital Logic Design including combinational circuits, sequential circuits, counters, shift registers, and finite state machines.

## 🎯 Objectives

* Build a strong foundation in Digital Design
* Practice RTL coding in Verilog HDL
* Develop modular design methodology
* Learn verification using testbenches
* Create a reusable library of digital circuits

---
