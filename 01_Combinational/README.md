# Combinational Circuits

This folder contains combinational logic circuits implemented in Verilog HDL.

## Circuits

1. Logic Gates
2. Multiplexer (MUX)
3. Demultiplexer (DeMUX)
4. Decoder
5. Encoder
6. Priority Encoder
7. Comparator
8. Half Adder
9. Full Adder
10. Ripple Carry Adder (RCA)
11. Carry Look Ahead Adder (CLA)
12. Parity Generator
13. Parity Checker
14. Binary to Gray Converter
15. Gray to Binary Converter
16. BCD to Excess-3 Converter
